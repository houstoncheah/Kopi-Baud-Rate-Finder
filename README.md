Kopi Baud Rate Finder

A standalone HTML tool for discovering serial device communication settings using the Web Serial API.

Features

Baud rate detection
RS232 connect and monitor page
Text and HEX view
Listen + Probe, Probe, and Listen-only modes
Command history cards
Custom line terminators
Log file output with date and time stamps
Light and dark theme
Single self-contained HTML file

Requirements

Microsoft Edge or Google Chrome
Serial device access permission

Privacy

No server
No cloud services
No network transmission of serial data
All processing runs in the browser

Usage

Open:
index.html
or
kopi-baud-rate-finder.html
Click Add, select a serial port, then begin scanning or connect directly.
